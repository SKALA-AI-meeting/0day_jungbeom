# debrief / 서두름형 로그

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 진입 | 종료 화면 | 끝났다는 한 줄과 핵심 | "수고하셨습니다" 아래 안내 문구가 이어지고, 맨 위에서 바로 보이는 것은 설명 글뿐. 서두르는 입장에선 가장 궁금한 "제출됐나"가 맨 아래 "제출한 기획안"까지 내려가야 보임 | 중 |
| 훑기 | 전체 | 짧게 훑기 | 한 페이지가 매우 길다(보는 요소 5개 설명, 내 발언, AI 동료 정체, 평가와 기록, 기획안, 설문). 위에서부터 글 위주라 훑기 어렵지만 소제목은 분명 | 하 |
| 훑기 | 내 발언 돌아보기 | 내 발언 확인 | 발언 3개가 시각과 함께 정리되어 있어 알기 쉬움 | - |
| 훑기 | 평가와 기록 | 결과 | "평가 결과는 보여 드리지 않습니다"라고 이유와 함께 명시. 기대를 접기엔 좋으나 서두르는 사람은 이 문장을 놓칠 수 있음 | 하 |
| 훑기 | 설문 | 빨리 보내고 끝 | 1~5 버튼과 의견칸, "모든 문항은 건너뛸 수 있고 한 번만 보낼 수 있어요" 안내. 설문 보내기는 맨 아래라 스크롤 필요. 설문은 건너뜀 | 하 |

좋았던 점: 동료 AI 성향 공개와 기획안 다시 보기·복사 버튼이 유용, 열람 기한(2026.10.28)과 보관 기간이 적혀 있음.
