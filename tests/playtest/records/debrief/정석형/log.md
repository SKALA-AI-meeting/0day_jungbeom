# debrief 단계 / 정석형

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 입장 | 종료 화면 | 종료 안내 | "수고하셨습니다"와 함께 보는 요소·내 발언·AI 동료 성향·평가와 기록·제출한 기획안·설문이 한 페이지에 나열됨. 읽기는 쉽지만 길다 | 하 |
| 읽기 | 평가와 기록 | 평가 결과 여부 | "평가 결과는 보여 드리지 않습니다" 이유와 보관 기간(90일), 문의처가 명확해 안심됨 | 좋음 |
| 읽기 | AI 동료 소개 | 정체 공개 | 동료가 정해진 성향의 AI였다는 설명과 성향별 설정이 나옴. 투명하지만 "평가 요소"가 모두 공개되어 앞선 행동을 되돌아보게 됨 | 하 |
| 복사 | 제출한 기획안 | 복사 | "복사했어요" 토스트 표시, 정상 | 좋음 |
| 설문 | 종료 설문 | 점수·의견 입력 후 전송 | 1~5 선택, 의견 입력, "설문 보내기" 후 "설문에 답해 주셔서 고마워요"로 교체됨. 정상. 전송 직전 화면 맨 아래라 스크롤이 필요했음 | 하 |
| 내 발언 | 돌아보기 | 내 발언 목록 | 발언 3개만 나옴(시드 세션 특성일 수 있음) | 하 |

좋았던 점: 평가 방식·기록 보관·문의처 안내가 정직하고 명확, 설문 완료 피드백 즉시 표시.
