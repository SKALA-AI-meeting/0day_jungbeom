# debrief / 서두름형 (박빠름)

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 진입 | 종료 화면 | 짧은 마무리 | 한 페이지에 설문·평가 안내·보는 요소·AI 동료·접힘 2개가 길게 이어짐. 대충 훑어도 설문이 맨 위라 바로 찾음 | 하 |
| 설문 | 종료 설문 | 점수 선택 후 전송 | 4·5점+의견 입력 후 "설문 보내기" → "설문에 답해 주셔서 고마워요." 바로 완료, 빠름. 보낸 뒤 내용 확인 불가(한 번만 보낸다고 안내됨) | - |
| 접힘 | 내 발언 돌아보기 | 내 말 목록 | 단계별 내 발언 3개가 시각과 함께 표시. 동료 말은 없어 내 것만 보는 점이 깔끔 | - |
| 접힘 | 제출한 기획안 | 내가 낸 내용 | 첫 클릭은 펼쳐지지 않았고(제목 텍스트 클릭), summary 선택자로 클릭하니 펼침. 사람 손으로는 한 번에 열렸을 수 있어 드라이버 영향 가능. 펼친 내용은 "2026. 10. 29.까지 다시 볼 수 있어요" + 6칸 + 복사 버튼 | 하 |
| 문구 | 평가와 기록 | 결과가 보임 | "평가 결과는 보여 드리지 않습니다"가 설문 아래 중간쯤에 있어 결과를 찾으려던 사람은 늦게 알게 됨 | 중 |

좋았던 점: 설문이 선택·1클릭 수준, 열람 기한 날짜 명시, 복사 버튼.
목표: 종료 후 화면 훑기, 설문 제출까지, 기획안·발언 보기까지. 달성.
