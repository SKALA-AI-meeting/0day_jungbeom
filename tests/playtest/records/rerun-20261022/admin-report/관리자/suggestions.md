# 개선 제안 (채용 담당자 입장)

1. 요약 서술과 차원 상태가 어긋나지 않게 하기. "근거 부족으로 낮은 수준"이라 쓰고 해당 차원이 기록 없음이거나 "기록 없음 차원은 없다"고 쓰고 보류 3개가 있는 경우가 보임. 서술을 차원 상태에서 만들거나 검증해 주세요.
2. 장면이 "이벤트 미발생"인데 그 장면을 근거로 낮은 수준을 주지 않도록. 수준과 근거 메시지, 장면 카드가 서로 맞는지 한 번 대조해 주세요.
3. 판단 보류를 요약에 개수로 보여 주고(예: "보류 4 · 원문 확인 필요"), 보류 항목마다 "원문 기록 보기" 링크를 붙여 다음 행동을 알려 주세요. "근거 약함 5"가 무엇인지 설명도 필요합니다.
4. 채용 건 목록에 지원자 이름·최근순 정렬·검색을 넣고, 상세에서 "리포트 준비 중"이면 안내와 자동 갱신을 해 주세요.
5. 점수처럼 읽히는 표현 줄이기: 서술의 "낮은 수준으로 평가되었다"·"미흡" 대신 관찰된 행동만 적고, 수준 숫자는 "참고 수준"임을 칩 옆에 짧게 표시해 주세요. 정직/공정은 "비워서 제출"과 "부정확하게 작성"을 구분해 주세요.
