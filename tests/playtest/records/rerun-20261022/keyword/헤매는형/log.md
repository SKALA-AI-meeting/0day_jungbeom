# keyword · 헤매는형 (이헤맴)

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 입장 | 동의 화면 | 이름 입력 전 "동의하고 계속"을 눌러 보면 이유를 알려줌 | 버튼이 흐려진 채 눌러도 반응 없음(5초 후 클릭 타임아웃). 체크박스를 안 체크해서라는 안내 없음 | 하 |
| 시작 직후 | 토론방 | 어디서 고르는지 바로 알기 | 우측 "결정 사항"에 후보 4개와 안내 문구가 있어 찾을 수는 있었으나, 처음엔 채팅 쪽만 보게 됨 | 하 |
| 시작 직후 | 자료/기획안 탭 | 눌러 보면 용도를 알 수 있음 | 자료: "키워드가 정해지면 자료가 열립니다" 안내로 이해됨. 기획안: 빈 칸이 모두 보이고 "기획안 작성 단계에서 제출할 수 있어요" 안내가 있어 안심됨 | - |
| 약 1분 | 토론방 | "키워드는 어디서 고르나요?"에 도움 되는 답 | 윤하람이 "결정 사항에서 직접 하시면 돼요"로 위치를 안내해 도움이 됨(좋음). 다만 같은 답을 서지안도 반복, 곧바로 자기 선호(나무/바람)를 밀어 부담스러움 | 하 |
| 약 3분 | 결정 사항 | 동료와 합의 없이 정해도 되는지 확인 | "동료 동의 없이 직접 골라도 되나요?"에 윤하람이 "직접 고르셔도 괜찮아요"로 답해 해소. 화면에는 합의가 필요한지 설명 없음 | 하 |
| 약 4분 | 확정 대화상자 | 되돌릴 수 있는지 알기 | "이걸로 정하면 다음 단계로 넘어가요" 문구와 취소/네 버튼으로 충분히 명확(좋음). 되돌릴 수 있는지는 안 나옴 | 하 |
| 약 5분 | 문제 상황 진입 | 다음 할 일 파악 | 문제 상황 입력칸이 열리고 단계 안내 메시지(27분 남음)가 나옴. 키워드 단계의 "이 단계 10분"과 달리 바뀐 시간 기준이 처음엔 의아함 | 하 |

좋았던 점: 시작 전 안내 화면(역할·탭 설명), 단계 진행바, 확정 대화상자, 질문에 윤하람이 위치를 알려 준 것. 상·중 항목 없음. 목표 달성(키워드 "나무" 확정, 문제 상황 단계 진입).
