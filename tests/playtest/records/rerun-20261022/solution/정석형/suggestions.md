# solution 개선 제안 (정석형 지원자 입장)

1. 호명 질문에는 호명된 동료가 먼저·직접 답하게 해 주세요. 서지안을 불렀는데 강한결이 먼저 답했고, 서지안의 답은 내 질문과 거리가 있었습니다.
2. 동료가 해결책을 말할 때 정한 문제 상황(도심 침수)과 맞는지 지켜 주세요. 절수 캠페인이 계속 나와 논점이 가뭄으로 흘렀습니다.
3. 결정 확정 뒤에는 이미 생성 중이던 동료 발언이 반대 입장을 새로 내지 않도록 걸러 주세요. 결정 직후 "이 안을 밀고 싶다"가 올라와 혼란스러웠습니다.
4. 채팅에도 "해결책이 ○○으로 정해졌어요" 같은 한 줄을 남겨 주세요. 오른쪽 패널과 단계 바로만 알 수 있었습니다.
5. 기획안 탭 첫 화면의 "6분 전 저장됨"은 막 시작한 상태에서는 숨기거나 "아직 저장 안 됨"으로 바꿔 주세요.
