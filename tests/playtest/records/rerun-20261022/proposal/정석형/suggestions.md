# proposal 개선 제안 (정석형 지원자 입장)

1. 제출 확인 창에 "빈 칸 0개" 또는 칸별 입력 요약을 보여 주세요. "수정할 수 없어요"만으로는 내용을 마지막으로 점검하기 어렵습니다.
2. 확인 창을 연 순간 하단이 "제출 중..."으로 바뀌지 않게 해 주세요. 취소하면 어떻게 되는지 불안합니다.
3. 확인 창 버튼 문구를 "네, 제출할게요"처럼 바꿔 뒤쪽 "제출" 버튼과 구분해 주세요(결정 확인 창은 "네, 정할게요"라 일관됨).
4. 새로 연 기획안의 저장 표시는 "저장됨"만 보여 주세요. "10분 전 저장됨"은 방금 시작한 사람에게 이상합니다.
5. 제출 후 채팅에 마무리 한 줄(제출 완료, 이후 절차)을 남겨 주세요.
