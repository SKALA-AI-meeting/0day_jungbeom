# proposal / 정석형 로그

세션 시작 시 이미 "이 단계 4:27 남음"(시드 시간이 지난 상태)이라 시간 여유가 짧았음. 이름 입력·동의 화면 없음("지원자-ba99e1").

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 시작 | 기획안 탭 | 기획안 탭을 눌러야 열림 | 이미 기획안 탭이 열려 있고 키워드·문제 상황·해결책이 미리 채워짐. 근거·기대효과·아이디어 기여 3칸만 비어 있어 직관적 | 좋음 |
| 시작 | 오른쪽 하단 | 저장 상태 | "10분 전 저장됨"(방금 연 화면인데 오래전으로 보임) | 하 |
| 입력 | 기획안 | 칸 안내 | 칸마다 설명(예: "이 기획에 반영된 의견과 그 의견을 낸 사람")이 있어 무엇을 쓸지 알 수 있었음. 다만 아이디어 기여 칸이 화면 아래쪽에 걸려 스크롤 필요 | 하 |
| 제출 클릭 | 확인 창 | 제출 전 확인 | "제출하면 수정할 수 없어요" 제목 + [취소][제출] 두 버튼만 나옴. 빈 칸이나 내용 요약은 없음. 확인 창이 뜬 동시에 뒤쪽 하단이 "제출 중..."으로 바뀌어, 아직 확인 전인데 제출이 시작된 것으로 보임 | 중 |
| 확인 창 | 버튼 | 구분되는 버튼 | 확인 창 버튼 이름이 뒤쪽 "제출" 버튼과 같아 텍스트로 클릭하면 어느 쪽인지 모호(css로 지정해야 했음) | 하 |
| 제출 후 | 상단/채팅 | 종료 안내 | 상단에 "제출했어요. 세션이 끝났습니다." + [나가기], 입력창은 "세션이 끝났어요"로 비활성, 기획안 칸 잠금, 하단 "제출했어요". 명확함 | 좋음 |
| 제출 후 | 채팅 | 마무리 인사 | 채팅에는 마무리 메시지·감사 문구 없음. 상단 한 줄이 전부여서 다소 건조 | 하 |
