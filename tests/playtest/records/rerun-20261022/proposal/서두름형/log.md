# proposal / 서두름형 (박빠름)

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 세션 시작 | 기획안 탭 | 빈 칸에서 시작 | 키워드·문제 상황·해결책은 이미 채워져 있고 "10분 전 저장됨"이라 표시. 내가 한 적 없는 입력처럼 보여 어리둥절(시드 세션 영향일 수 있음) | 하 |
| 입력 | 칸 채우기 | 근거 칸에 입력 | 내 조작(placeholder 기준 fill)이 키워드 칸에 들어가 키워드가 "매년 반복되는 침수"로 바뀜. 드라이버 지정 오류 가능성이 크고 제품 문제로 단정하지 않음 | 하 |
| 제출 1 | 모달 | 바로 제출 | "비워 둔 칸이 있어요. 그대로 제출할까요?" + 칸 이름(근거, 기대효과, 아이디어 기여) + [돌아가서 쓰기][그대로 제출]. 비운 칸이 명확해 좋았음 | - |
| 제출 1 | 모달 뒤 화면 | 제출 전 상태 | 뒤 화면 하단에 "제출 중…"이 이미 표시됨(확인 전인데 제출 중처럼 보임) | 하 |
| 제출 2 | 모달 | 한 번에 끝 | "제출하면 수정할 수 없어요" [취소][제출] 두 번째 확인이 또 나옴. 서두르는 사람은 확인 두 번이 번거롭지만 되돌릴 수 없다는 안내는 도움 | 중 |
| 제출 후 | 헤더 | 종료 안내 | "제출했어요. 세션이 끝났습니다." + [나가기]. 입력창은 "세션이 끝났어요"로 잠김 | - |
| 종료 화면 | 수고하셨습니다 | 요약 | 설문·평가 안내·보는 요소·AI 동료 공개·내 발언 돌아보기·제출한 기획안이 한 페이지에 길게 나열. 훑기엔 길지만 순서는 이해됨 | 하 |
| 종료 화면 | 제출한 기획안 | 펼쳐서 내용 확인 | 클릭 후 텍스트 상 펼쳐진 내용이 확인되지 않음(스크린샷으로 재확인 못 함) | 하 |

좋았던 점: 빈 칸 경고가 칸 이름까지 알려 줌, 제출 불가역 안내, 종료 화면에 AI 동료 공개.
목표: 칸 일부만 채우고 빈 채 제출 시도 → 모달 확인 → 종료 화면 도달. 달성.
