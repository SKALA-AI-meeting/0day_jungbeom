# keyword / 서두름형 로그

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 시작 | 안내 2장(소개·동의) | 훑고 바로 시작 | "다음" -> 동의 체크 + 이름 -> 준비 화면 -> "시작하기"까지 4번 클릭. 안내 글이 길지만 버튼은 눈에 잘 띔 | 하 |
| 09:00 | 토론방 첫 화면 | 내가 정할 수 있게 열림 | 강한결이 먼저 "불이 적합"이라 말함. 서지안은 곧 "바람"을 제안했는데, 나는 이를 기다리지 않고 불을 누름 | - |
| 09:51 | 결정 사항 > 이걸로 정하기 | 한 번에 확정 | 확인 대화상자가 한 번 더 뜸(키워드: 불, 취소/이걸로 정하기). 서두르는 입장에선 한 번 더 클릭이 번거롭지만 실수 방지로는 적절 | 하 |
| 확정 직후 | 결정 사항 키워드 | 동료 의견 반영 여부 표시 | 서지안(바람 선호)과 의견이 갈렸는데 "합의 / 정한 사람 · 나"로 바로 표시됨. 동료 동의 없이 혼자 눌러도 "합의"가 됨 | 중 |
| 확정 직후 | 다음 단계 | 바로 문제 상황으로 | 즉시 단계 전환, 강한결이 "자료부터 같이 보고 얘기해요" 안내. 자료 탭에 새 글 표시(점 1) | - |

좋았던 점: 키워드 후보 4개가 버튼으로 바로 보여 빠르게 고를 수 있음, 단계 전환이 즉각적, 시간 표시 명확.
