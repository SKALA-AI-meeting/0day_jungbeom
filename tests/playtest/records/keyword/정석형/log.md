# 불편 로그 (정석형 · 키워드 단계)

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 토론 시작 직후 | 토론방 | 어떤 프로젝트·주제의 키워드인지 알려 주는 안내 | 물·불·나무·바람 중 고르라는 말뿐이고, 키워드가 무엇을 위한 것인지(문제 상황의 출발점 등) 설명이 없음. 한결이 곧바로 "불이 맞아요"라고 해 맥락 없이 주장만 오감 | 중 |
| 시작 직후 | 결정 사항 탭 | 키워드를 어떻게 정하는지(전원 동의 필요 여부) 안내 | 한결(불)이 끝까지 반대했는데도 내가 "이걸로 정하기"를 눌러 바로 확정됨. 확정 팝업에도 동의 여부 언급이 없고, 상단에는 "합의"로 표시되어 실제와 다름 | 중 |
| 첫 발언 직후 | 토론방 | 내가 지목한 윤하람님이 먼저 답함 | 한결·지안이 먼저 답하고 하람은 한참 뒤에 말함. 지안은 내가 한 질문("윤하람님은 어떻게 생각하세요?")을 그대로 되묻기도 함 | 하 |
| 발언 2~4회 | 토론방 | 동료들이 내 제안·질문을 반영한 답 | 한결은 내 질문을 바꿔 물어도 "불이 유용하다"를 반복, 하람은 같은 문장을 반복("나무를 후보로 밀어보려 합니다"). 토론이 진전되지 않고 로봇 같음 | 중 |
| 확정 팝업 | 결정 확인 | 팝업 버튼이 뒤 패널 버튼과 구분됨 | 같은 이름 "이걸로 정하기"가 팝업과 패널에 둘 다 있어 텍스트 클릭이 모호함(이번엔 팝업이 눌림) | 하 |
| 시작 화면 | 첫 안내 | 짧고 읽기 쉬운 안내 | 첫 화면 문단이 길고 한 덩어리, 다음 동의 화면과 내용이 상당 부분 중복 | 하 |
| 단계 전환 직후 | 토론방 | 새 단계 안내 후 무엇을 할지 | 한결이 "자료부터 같이 보고 얘기해요"만 말함. 자료 탭에 새 알림(1)이 뜨지만 토론방 안에서 어디를 보라는 안내는 없음 | 하 |

## 좋았던 점
- 동의 화면에서 평가 방식·기록 항목을 솔직하게 설명해 안심이 됨.
- 시작 전 화면 구성 안내(상단 진행바·토론방·우측 탭)가 명확해 길을 잃지 않음.
- "OO님이 입력 중" 표시와 동료별 말풍선 색 구분이 좋음.
- 단계 진행바와 남은 시간이 보이고, 확정 시 체크 표시로 단계가 넘어간 게 분명함.
