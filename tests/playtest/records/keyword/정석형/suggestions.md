# 지원자 입장 개선 제안

1. 키워드 단계 첫 안내에 "이 키워드로 다음 단계에서 어떤 문제 상황을 다루게 되는지"를 한두 줄 덧붙인다. 지금은 무엇을 기준으로 고르는지 알 수 없다.
2. 확정 규칙을 미리 알려 준다. 혼자 눌러도 되는지, 동료 동의가 필요한지 안내하고, 확정 팝업과 "합의" 표시도 실제 상태(예: 한결은 반대)에 맞춘다.
3. 내가 지목한 동료가 먼저 답하게 하고, 다른 동료가 내 질문을 그대로 되묻지 않게 한다.
4. 동료가 이전 발언을 반복하지 않고, 내가 제안한 근거(예: 대기 질이라는 공통점)에 직접 반응하게 한다. 입장이 바뀌면 이유를 말하게 한다.
5. 확정 팝업의 버튼 문구를 "나무로 확정"처럼 패널 버튼과 다르게 하고, 새 단계 시작 시 자료 탭으로 가는 바로가기를 토론방에 둔다.
