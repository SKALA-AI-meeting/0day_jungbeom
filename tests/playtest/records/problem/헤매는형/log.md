# problem 헤매는형 log

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 진입 | 토론방 | 지금 상황 파악 | 5:30 남은 채 시작. 위 대화는 이미 쌓여 있는데 키워드가 "물"인데 한결·지안은 "불" 얘기를 하고 있어 맥락이 어긋나 혼란(시드 대화일 수 있음) | 중 |
| 진입 | 결정 사항 | 무엇을 쓰는지 알기 | 문제 상황 칸이 빈 입력상자뿐, placeholder·예시 없음. 시스템 메시지의 "문제 상황 하나를 정해 주세요"로만 짐작 | 중 |
| 탐색 | 자료 탭 | 자료 열람 | 자료 4개 목록, 침수 사례를 열어 보니 통계·원인 정리돼 있어 유용. 다만 읽다 보면 시간(4~5분)이 빠르게 줄어 불안 | 하 |
| 질문 | 채팅 | "침수 괜찮나요?" 답 | 윤하람 "조금 더 들어볼게요", 서지안 "어떤 점에서 중요한가요? 근거 있으면"으로 되물음. 방향 확인은 못 받았지만 대화 흐름은 자연스러움 | 하 |
| 입력 | 오른쪽 입력칸 | 결정 입력칸에 쓰기 | 포커스가 채팅창에 있어 문제 상황 문구가 채팅 입력창에 들어감(내 실수, 두 입력칸이 비슷해 혼동). 지우고 오른쪽에 다시 입력. 이걸로 정하기는 입력 전 비활성이라 눌러도 반응 없음(이유 표시 없음) | 중 |
| 확정 | 확인창 | 확정 | "다음 단계로 넘어가요" 확인창에 내용 표시. 확정 후 해결책 단계로 진입(목표 달성) | - |

좋았던 점: 확정 확인창, 합의 배지, 자료 신규 점·목록 이름이 쉬움, 동료가 질문에 반응.
소요 약 3분.
