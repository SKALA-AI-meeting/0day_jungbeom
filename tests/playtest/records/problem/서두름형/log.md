# problem / 서두름형 로그

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 시작 | 토론방 | 문제 상황 단계 시작 | 시드 시작인데 앞 단계 대화(내가 "물이 좋겠어요", 강한결 불 주장 등)가 이미 있고, 내 이름이 "지원자-d76e13"으로 나옴(이름 입력 단계 건너뜀 시드 특성으로 보임) | 하 |
| 문제 상황 입력 | 오른쪽 결정 사항의 입력칸 | 눈에 띄는 입력칸에 바로 씀 | 입력칸에 라벨·안내 문구가 없어 "문제 상황" 글자만 보임. 텍스트 입력 도구가 먼저 채팅창으로 들어가 채팅으로 전송됨(화면상 두 칸 구분이 약함) | 중 |
| 입력 후 | 결정 사항 | 버튼 활성화 | 글자 입력하면 "이걸로 정하기"가 파랗게 활성화, 이해하기 쉬움 | - |
| 확정 | 확인 대화상자 | 한 번에 확정 | 대화상자가 한 번 더 뜸. 버튼 문구가 뒤 화면 버튼과 똑같아서 같은 글자 버튼 두 개라 헷갈림 | 하 |
| 확정 직후 | 결정 사항 | 동료 동의 확인 | 서지안이 "다른 원인도 있는지 궁금"이라며 의문을 냈는데도 내가 누르자 바로 "합의"로 표시됨 | 중 |
| 확정 직후 | 다음 단계 | 해결책으로 넘어감 | 즉시 해결책 입력칸이 열림. 빠르게 지나갈 수 있어 좋음. 단 동료 답변이 계속 이어져 반응을 안 읽어도 진행됨 | - |

좋았던 점: 단계 진행바와 남은 시간이 잘 보임, 확정 버튼 활성화 규칙이 분명, 단계 전환 즉시.
