# problem 단계 / 정석형 (김정석 역할)

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 입장 | 입장 직후 채팅 | 입장·동의·표시 이름 입력 화면 | 입장·이름 입력 없이 바로 채팅. 이름은 "지원자-a48edc"로 자동 부여, 키워드 단계 대화(내 발언 포함)가 이미 진행된 상태로 시작 | 중 |
| 입장 | 결정 사항 패널 | 키워드를 내가 어떻게 정했는지 알 수 있음 | 키워드 "물 · 정한 사람 나"로 이미 합의됨. 내가 하지 않은 일이 내 행동으로 보여 어리둥절 | 중 |
| 5:23 남음 | 상단 타이머 | 안내문 "이 단계 6분"과 일치 | 안내문 6분, 화면 5:23으로 불일치(단계 시작 후 시간이 이미 흐름) | 하 |
| 시작 | 자료 탭 | 자료 목록→상세 | 목록 4개, 상세 표·불릿이 잘 읽힘. "토론용으로 만든 가상의 지역 자료" 표기 명확 | 좋음 |
| 발언1 | 채팅 | 동료가 내 제안(도심 침수)에 반응 | 서지안이 문제 상황 단계인데 "해결 방안은?"으로 해결책을 먼저 물음 | 하 |
| 발언2~3 | 채팅 | 동료 입장이 일관됨, 지목한 하람이 답함 | 한결·서지안이 직전에 침수에 동의하던 태도에서 가뭄으로 갑자기 바뀜. 한결은 같은 문장을 되풀이. 하람은 "저는 조금 더 들어볼게요" 한 번 뒤 끝까지 답 없음(직접 질문해도) | 중 |
| 결정 | 결정 사항 입력란 | 라벨/안내가 있는 입력란 | 입력란에 라벨·placeholder 없고 비어 있으면 버튼이 비활성(옅은색)이라 처음엔 어떻게 쓰는지 모호. 입력 후 활성화됨 | 중 |
| 결정 | 확인 대화상자 | 합의 확인 | "이걸로 정하면 다음 단계로 넘어가요" 확인창. 명확해서 좋음. 다만 동료 중 누구도 침수에 동의하지 않았는데 혼자 확정 가능했고 "합의"로 표시됨 | 중 |
| 결정 후 | 단계 전환 | 다음 단계 안내 | 상단 진행 표시 체크, 시스템 안내 "해결책 단계예요… 8분 남았어요" 바로 나옴. 전환 매끄러움 | 좋음 |

좋았던 점: 진행 표시줄·타이머·자료 표기·확인창이 명확, 입력 중 표시와 자동 스크롤 동작.
