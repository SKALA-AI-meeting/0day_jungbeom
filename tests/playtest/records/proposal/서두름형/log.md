# proposal / 서두름형 로그

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 시작 | 기획안 탭 | 입력칸이 보이고 바로 씀 | 단계 시작 시 남은 시간이 4분 30초뿐(시드 영향 가능). 키워드·문제·해결책은 미리 채워져 있어 빨라 좋음. 상단 "10분 전 저장됨"이 낯설음 | 하 |
| 근거 입력 | 근거·기대효과·아이디어 기여 | 입력칸이 칸처럼 보임 | 입력칸이 테두리 없이 밑줄뿐이고 안내 문구가 작은 회색 글자라, 눌러도 되는 칸인지 불분명. "textarea" 순서로는 못 잡고 설명 문구를 눌러야 포커스됨. 한 줄처럼 보여 긴 글을 쓸 칸인지 모호 | 중 |
| 해결책 칸 | 기획안 | 내가 말한 안 반영 | 기획안의 해결책이 "센서·데이터 기반 물 관리·경보"로 이미 채워져 있음(내 발언과 거의 같음). 서지안은 주민 캠페인을 말했으나 반영 칸에는 따로 표시 없음 | 하 |
| 제출 | 제출 확인 | 한 번에 제출 | "제출하면 수정할 수 없어요" 대화상자가 뜸(취소/제출). 경고 문구가 분명해 좋음. 필수 칸 검증 없이 비어 있어도 되는지는 확인 못 함 | 하 |
| 제출 후 | 상단·채팅 | 완료 안내 | "제출했어요. 세션이 끝났습니다." + "나가기" 버튼 표시, 채팅창은 "세션이 끝났어요"로 비활성. 명확함 | - |

좋았던 점: 앞 단계 결과가 기획안에 자동으로 채워짐, 제출 후 상태 표시가 분명, 단계 전환 즉시.
