# 채용 담당자 입장 개선 제안

1. 채용 건 목록에 검토 필요/완료 건수 열을 넣고, 이름이 같은 건을 구분할 수 있게 하며 최신순 정렬 또는 필터를 준다.
2. "판단 실패"가 있는 요소는 요소 요약 위에 한 번에 알리고(예: 자동 판단이 안 된 차원 N개), 재판단 요청 또는 원문 직접 평가 안내를 붙인다.
3. 근거 약함·확신도 낮음이 많은 차원은 근거 메시지 수를 같이 보여주고, 근거가 1건뿐이면 판단 이유 서술을 단정형으로 쓰지 않게 한다.
4. 카드 장면의 "이벤트 미발생"이면 설명문을 "발생하지 않음: 이런 장면이었습니다"처럼 가정형으로 바꿔 발생한 것으로 읽히지 않게 한다.
5. 조정 후에는 판단 이유 옆에 "담당자 메모 반영됨"을 같은 영역에 붙이고, 검토 완료 확인창은 현재 보이는 위치에 띄운다.
