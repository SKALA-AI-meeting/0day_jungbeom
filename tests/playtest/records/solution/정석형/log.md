# solution 단계 / 정석형

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 입장 | 채팅 | 이 단계 이전 맥락을 알 수 있음 | 앞 단계 대화·결정(키워드 물, 문제 상황 "도심 폭우·침수 피해 증가", 정한 사람 나)이 이미 있음. 내가 안 한 발언이 내 말로 보임 | 하 |
| 5:45 | AI 어시스턴트 탭 | 열린 자료 기반 답 | "빗물 재이용 사례" 질문에 "자료를 찾을 수 없습니다. 키워드를 정해주시면 다시 시도해 볼 수 있습니다"라고 답함. 키워드는 이미 "물"로 합의된 뒤라 사실과 안 맞음 | 중 |
| 5:03 | AI 어시스턴트 탭 | 보내기 버튼 클릭 | 하단 "보내기"가 텍스트로 클릭이 안 되는 경우가 있어 css로 지정해야 했음(드라이버 쪽 이슈일 수 있음) | 하 |
| 발언1~3 | 채팅 | 동료와 의견 교환 | 한결(센서 경보)·지안(절수 캠페인) 안이 문제 상황(침수)과 맞지 않는 안을 지안이 내놓음. 내가 지적하니 비용 근거로 반박, 한결이 비용은 시범으로 해결된다고 호응, 하람이 처음에 "먼저 얘기하세요" 하다 마지막에 빗물 저금통 안을 냄. 토론 흐름 자연스러움 | 좋음 |
| 발언 | 채팅 | 지안이 자기 안에 대한 질문 | 지안이 자기 안의 근거를 나에게 물어 방향이 살짝 뒤집힘("제 안이 침수에 어떻게 기여할까요?") | 하 |
| 결정 | 결정 사항 입력란 | 라벨/안내 | 여전히 입력란에 안내가 없고, 비면 버튼 비활성 | 하 |
| 결정 | 확인창 | 단계 이동 전 확인 | 동료 3명 중 누구도 센서 안에 최종 동의한 표현은 없는데(한결만 찬성, 지안 반대, 하람 다른 안) 혼자 정해 "합의"로 넘어감. 하람의 안은 반영 안 됨 | 중 |
| 결정 후 | 기획안 탭 | 다음 단계 안내 | 기획안 탭 자동 열림, 앞에서 정한 세 항목이 채워져 있고 안내 문구 "남은 시간 7분" 명확 | 좋음 |
| 결정 후 | 기획안 하단 | 저장 상태 | "7분 전 저장됨"이 방금 열린 빈 기획안에 보임. 의미 불명 | 하 |

좋았던 점: 동료가 근거를 요구하고 반박해 토론다웠음, 단계 전환과 기획안 탭 자동 전환이 매끄러움.
