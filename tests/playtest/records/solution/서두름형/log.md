# solution / 서두름형 로그

| 시각 | 화면 | 기대한 것 | 실제 | 심각도 |
|---|---|---|---|---|
| 시작 | 토론방 | 해결책 단계 시작 | 시드로 시작하니 앞 단계 합의(물, 도심 폭우·침수)가 이미 있고 내 이름이 "지원자-86f588"로 나옴. 해결책 입력칸이 바로 열려 있어 빨리 쓰기 좋음 | 하 |
| 입력 | 결정 사항 입력칸 | 입력칸 바로 인지 | 이번에도 입력칸에 안내 문구가 없음. 앞서 겪어서 알고 있었으나 처음이면 채팅창과 헷갈릴 듯 | 중 |
| 확정 | 확인 대화상자 | 한 번에 확정 | 같은 글자 버튼 두 개짜리 대화상자가 또 뜸 | 하 |
| 확정 직후 | 토론방 | 동료 반응 | 강한결이 "센서와 데이터 기반 물 관리 시스템이 필요" 등 내 해결책(저류조·경보)과 다른 방향을 말했는데도 내 안이 그대로 "합의" 처리되고 기획안 단계로 넘어감 | 중 |
| 기획안 탭 | 기획안 | 비어 있음 | 비어 있는 상태인데 "5분 전 저장됨"이라고 떠 있음. 저장된 내용이 없는데 시각이 있어 혼란 | 하 |

좋았던 점: 확정 즉시 기획안 탭이 자동으로 열리고 입력칸 6개(키워드·문제·해결책 자동 채움)가 한눈에 보임, 안내 메시지가 토론방에 남음.
