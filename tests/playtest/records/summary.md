# playtest 요약 (2026-10-21, 실 LLM gpt-4o-mini, Playwright 드라이버)

블라인드 페르소나 4종이 단계 시드 세션(problem 이후는 15분, keyword는 입장부터 60분)에서 직접 조작했다. 영상·스크린샷은 커밋하지 않고 로컬에만 둔다. 반영 여부는 사람이 정한다.

| 단계 | 정석형 | 서두르는 형 | 헤매는 형 | 관리자 |
|---|---|---|---|---|
| keyword | 달성(중 3) | 달성(중 1) | 달성(중 4) | — |
| problem | 달성(중 4) | 달성(중 2) | 달성(중 3) | — |
| solution | 달성(중 2) | 달성(중 2) | 달성(중 3) | — |
| proposal | 달성(중 1) | 달성(중 1) | 달성(중 2) | — |
| debrief | 달성(중 0) | 달성(중 1) | 달성(중 2) | — |
| admin-report | — | — | — | 달성(상 1·중 4) |

심각도 상: 1건(관리자 — 리포트 차원 다수가 "판단 실패"라 리포트만으로 판단 불가).

## 여러 페르소나가 겹쳐 지적한 것

| 주제 | 내용 | 페르소나 |
|---|---|---|
| "합의" 표시 | 동료가 반대·질문 중인데 지원자 혼자 확정해도 결과가 "합의"로 표시됨(계약상 지원자 확정은 `resolution: consensus`) | 정석·서두름·헤매는 |
| 입력칸 안내 | 결정 사항·기획안 입력칸에 placeholder·예시·테두리가 약해 채팅 입력창과 혼동, 비활성 버튼 이유 없음 | 서두름·헤매는·정석 |
| 동료 응답 | 같은 주장 반복, 지원자 근거·진행 질문("어디서 고르나요?")에 직접 답하지 않음, 지목한 동료가 답하지 않음 | 정석·헤매는 |
| 맥락 안내 | 키워드가 무엇을 위한 것인지, 어디서 고르는지 안내 부족 | 정석·헤매는 |
| 디브리핑 길이 | 화면이 길고 설문·제출 확인이 맨 아래 | 서두름·헤매는·정석 |
| 확인 창 버튼 | 확인 창 버튼과 패널 버튼 이름이 같음("이걸로 정하기") | 정석·서두름 |
| 리포트 판단 실패 | 19개 차원 중 여러 개가 `evaluate_failed` | 관리자 |
| 어시스턴트 자료 없음 | 키워드 확정 뒤에도 자료를 찾지 못함 → 원인: 카탈로그 버전 변경 뒤 rag 색인 미갱신(재색인으로 해소, 단언 추가 중) | 정석 |

## 시드 특성(버그 아님)

시드 세션은 표시 이름이 자동(`지원자-xxxx`)이고 앞 단계 대화가 시드 문장이며, `ended` 시드는 카드 장면이 미발생이고 기획안이 시드 내용이다.

단계·페르소나별 상세는 `<단계>/<페르소나>/log.md`·`suggestions.md`.
