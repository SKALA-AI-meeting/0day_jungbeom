열린 UX 항목,
직접 보고 골라 주세요

지원자 토론 화면과 기업 리포트에서 아직 정하지 않은 항목 10개입니다. 항목마다 후보안 2~3개를 실제 화면처럼 그렸습니다. 예시 대화는 모두 키워드 「물」로 토론하는 장면입니다.

사용 방법

  1. 항목마다 후보안을 비교하고 하나씩 고릅니다. 후보안 아래 [이 안으로]를 누르면 화면 아래 막대에 쌓입니다. 고른 내용은 이 브라우저에만 남습니다.
  2. 다 골랐으면 아래 막대의 [선택 복사]로 복사해 붙여 주거나, “1-A, 2-B, 3-A…”처럼 말로 알려 주세요. 고치고 싶은 점은 한 줄 덧붙이면 됩니다.
  3. ★ 추천은 목업을 먼저 그릴 기준안입니다. 다른 안을 골라도 됩니다.
  4. 오른쪽 위 [라이트]·[다크]로 모든 목업을 두 모드에서 볼 수 있습니다. 일부 후보안은 [다시 보기]나 직접 눌러 보는 데모가 있습니다.
