## 5) 좋았던 점 3개

1. **개인 알림 채널의 구분.** "나에게만" 레일 묶음, "나만 받는 알림" 헤더와 내 아바타 하나, "리서치 담당 → 나에게만" 메타, 공개 때 "공개됐어요" 줄까지 이어져 "다들 봤겠지"가 성립하지 않는다. 이전 리뷰에서 가장 위험했던 모호함이 깔끔하게 풀렸다. `30-notice-channel.png`, `31-scene-70-released.png`
2. **받은 문서를 열어 둔 채 최종본을 고치는 동선.** 가운데 DocViewer와 오른쪽 ★ 최종본이 동시에 보이고, 가져오면 "도현 v1에서", 고치면 "도현 v1 + 편집" 칩이 바로 바뀐다. 분할 보기 없이도 "받은 것 보면서 내 것 고치기"가 된다. 보드는 동그라미 메뉴로 5장을 빠르게 채우고 확정 띠가 초록으로 바뀌어 상태가 분명하다. `23-finaldoc.png`, `25-final-edited.png`, `08-board-confirmed.png`
3. **리포트의 읽는 순서.** 요약표(세 수·한 줄 관찰) → 접힌 카드(항목 칩 미리보기) → 펼치면 상황·근거·"기록 기반/AI 분류 기반" 칩 → "기록에서 보기" 하이라이트. 합격·순위 표현이 어디에도 없고, 값을 바꾸면 메모 칸이 빨갛게 필수로 열리며, 확정 실패 문구가 담당자의 불안("조정이 날아갔나")을 정확히 겨냥한다. `60-report-top.png`, `62-report-card-open.png`, `69-record-highlight.png`, `81-approve-failed.png`
