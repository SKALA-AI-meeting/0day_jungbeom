     행 설정에도 이 값을 지정하지 않아, 일반 기동에서는 M1 완료 기준인 실
     제 그래프→RAG→응답 흐름이 실행되지 않습니다. 정상 실행의 기본값을 세
     션 러너로 바꾸거나 실행 설정에 AGENT_RUNNER=session을 명시하고 기동
     경로를 확인해야 합니다.

  2. 높음 · 도구 호출 상한 이후 응답 루프가 끝나지 않을 수 있음 — nodes.py
     (services/api/app/agent/session/nodes.py:231)
     호출 3회 뒤에도 모델이 tool_calls를 반환하면 limit_exceeded 결과를 붙
     여 다시 모델을 호출하는 과정이 무한 반복됩니다. 호출 상한 도달 시 루
     프도 종료하고 폴백하도록 수정하고, 연속 도구 호출을 반환하는 FakeLLM
     사례로 검증해야 합니다.

  3. 높음 · 점수 금지 필터 우회 — guard/init.py (services/api/app/agent/
     guard/__init__.py:28)
     unless가 문장 전체에 적용됩니다. 직접 실행한 Guard.apply("리드님 현재
     점수는 80점이고 재참여율은 22%예요.")는 hits=()로 원문을 그대로 반환
     했습니다. 점수 표현과 업무 지표를 별도 절로 검사하거나 금지 점수 표현
     을 우선 차단해야 합니다. 혼합 문장 테스트도 필요합니다.

  4. 중간 · 팀장에게 허용되지 않은 문서 조회 도구 노출 — nodes.py
     (services/api/app/agent/session/nodes.py:227)
