# stage-e2e에서 본 문제 (LLM_FAKE=1, track/stage-e2e)

7개 spec은 모두 통과했다. 아래는 통과하면서 관찰한 것이며 테스트를 억지로 맞춘 곳은 없다.

## 버그 후보

| # | 영역 | 심각도 | 내용 | 재현 |
|---|---|---|---|---|
| 1 | web 관리자 리포트 | 하 | 끝난 세션의 리포트 링크를 draft 생성 전에 열면 "report not found" 경고만 보이고 자동 재시도·"만드는 중" 안내가 없다. 새로고침해야 한다 | `make stage STAGE=ended`로 만든 `admin_report_url`을 바로 연다(워커가 1~2초 안에 만들기 전). spec은 `status == report_ready`를 기다린 뒤 연다 |

## 관찰(버그 아님, 테스트 주의점)

- **연속 전송은 앞 응답을 버린다.** 설계(낡은 generation의 화자 버림)대로지만 소극형 지명 직후 곧바로 다음 메시지를 보내면 소극형이 말하지 않는다. solution spec은 메시지마다 AI 응답이 가라앉을 때까지(`settle`) 기다린다.
- **카드 관찰은 카드 발언 게시 뒤에 기록된다.** 화면에 발언이 보인 직후 `GET /internal/.../observations`가 비어 있을 수 있어 problem spec은 poll로 기다린다.
- **"입력 잠김"**: testing.md의 problem 확인 항목 중 입력 잠김은 시간 초과 뒤 그 칸의 입력이 결과 줄로 바뀌고 다음 칸 입력이 열리는 것으로 확인했다. 입력창 비활성(`세션이 끝났어요`)은 세션이 끝난 proposal spec에서 확인한다.
- 시드 세션의 표시 이름이 별칭(`지원자-xxxxxx`)이라 AI 동료가 "지원자-xxxxxx님"으로 부른다(시드 전용).
- 결정적 LLM 모드에서 서지안이 같은 입장 문장을 연달아 두 번 내는 장면이 있다(고정 문장 특성).
