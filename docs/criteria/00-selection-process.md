# 평가 기준 재정의 — 선정 기준과 프로세스 (v1.0)

> **상태**: 분석 완료 → 결과는 [01-analysis-results.md](01-analysis-results.md). D3·D4(Schwartz 가치)는 접근 제한으로 미분석, D5는 불필요해 받지 않음.

> 목적: "무엇을 관찰할지"를 직관이 아니라 **공개 설문 데이터 분석**으로 정당화하고,
> 그 결과(최상위 개념)를 **직군·산업군별 딜레마 시나리오**로 바꿔 지원자의 선택과 의견을 관찰한다.
> 지원자에게는 상황만 주어지고, 어떤 개념 쌍을 보는지는 가려진다(PRD 5.5 원칙 3 유지).

## 1. 개념 관계의 두 유형

| 유형 | 정의 | 데이터에서의 판정 | 시나리오에서의 쓰임 |
|---|---|---|---|
| **(1) 대립·상보** | 한쪽을 추구하면 다른 쪽과 긴장(대립)하거나 함께 강화(상보)되는 개념 쌍 | 상관 r ≤ −0.20 → 대립, r ≥ +0.30 → 상보. 가치 데이터는 ipsative 중심화 후 MDS 원형 배치에서 대척/인접 | **딜레마**: 대립 쌍 A↔B 중 무엇을 우선하는지 선택 + 근거. 상보 쌍은 "둘 다 살리는 제3안"이 가능한지를 봄 |
| **(2) 독립** | 서로 거의 무관해서 따로 재야 하는 개념 | \|r\| < 0.10 (95% CI가 ±0.10 안) | **통제 변수**: 한 시나리오에 독립 차원 두 개를 섞어도 서로 오염되지 않음 → 문항 간 교락 방지 |

예시 가설(데이터로 검증할 것):
- "성과·능력(Achievement/Power) ↔ 배려·당위(Benevolence/Universalism)": Schwartz 이론상 **대립**.
- "자율·개방(Self-Direction) ↔ 통제·안정(Conformity/Security)": Schwartz 이론상 **대립**.
- "성실성 ↔ 능력": 직관과 달리 **독립(유형 2)**일 가능성이 높다는 선행 보고가 있음. 능력 측정 데이터가 확보될 때만 검증하고, 그 전에는 '가설'로만 표기.

## 3. 분석 프로세스 (사전 고정)

1. **정제**: 무성의 응답 제거(연속 동일 응답 ≥ 문항의 50%, 응답 시간 하위 1%), 역문항 코딩. 제외 비율을 보고.
2. **신뢰도**: 척도별 Cronbach α / McDonald ω. **ω < .70 척도는 후보에서 제외**.
3. **구조 확인**: 평행 분석으로 요인 수 결정 → EFA(oblimin) → D2로 교차 재현(Tucker φ ≥ .90).
4. **관계 행렬**: 척도 점수 간 상관(부트스트랩 1,000회 95% CI) → 유형 (1)/(2) 판정. 가치는 개인 평균 중심화 후 MDS로 원형 확인.
5. **사람 간 차이(변별력)**: 대립 쌍마다 개인별 차이 점수 d = A − B를 계산.
   - 분포의 표준편차, A 우선/B 우선 비율(균형이 50:50에 가까울수록 좋은 딜레마)
   - 극단 집중도가 낮을 것(한쪽이 90% 이상이면 "정답이 있는 질문" → 탈락)
6. **공정성**: 성별·연령대별 평균 차이 효과크기 \|d\| ≥ 0.5인 쌍은 보조 지표로만 사용(집단 편향 위험).
7. **최상위 개념 선정**: 아래 점수표로 순위화.

## 4. 최상위 개념 선정 점수표

| 기준 | 판정 방법 | 가중 |
|---|---|---|
| 측정 신뢰도 | ω ≥ .80 = 2, .70–.80 = 1 | 1 |
| 사람 간 분산 | d 분포 SD 상위 1/3 = 2, 중간 = 1 | 2 |
| 딜레마 균형 | A/B 우선 비율 40–60% = 2, 30–70% = 1 | 2 |
| 직무 관련성 | 직무 성과·반생산적 행동과의 관련이 메타분석에서 보고됨 = 2, 이론적 관련 = 1 (출처 명시) | 2 |
| 텍스트 관찰 가능성 | 메신저 대화의 선택·근거로 드러남 = 2, 간접 = 1 | 1 |
| 공정성 | 집단 차이 \|d\| < 0.2 = 2, < 0.5 = 1 | 1 |

상위 4~6개 개념(또는 대립 쌍)을 PR2 관찰 대상으로 확정하고, 기존 C01·C02·C03·C05와의 대응표를 만든다.

### 분석 중 추가한 규칙 (사후 추가, 결과 문서에 이유 명시)
- **X1** 정서성(불안·두려움·의존성·감상성) 측면은 딜레마 극으로 쓰지 않음 — 정신건강 근접성·큰 성차
- **X2** ipsative 대립만 있는 쌍은 원점수 r 95% CI 상한 < 0 이어야 함 — 평균을 빼는 과정에서 생기는 인공 대립 차단
- **X3** 점수 ≥ 만점의 60%
- **X4** 한 측면은 한 쌍에만 사용 — 축끼리 개념이 겹치지 않게
- 공정성 점수: 대응 지표가 없으면(정직-겸손) '알 수 없음' = 1점

## 5. 직군·산업군 → 문제 시나리오 후보

0. 축 배정: `1.5 × 직무 가중 + 산업 가중` 최댓값(동점은 직무 가중 → V1~V4 순). 가중치는 설계 가설로 `backend/app/criteria.py`에 이유와 함께 둔다.
1. 직군(기획/개발/디자인/영업·CS/운영) × 산업군(핀테크, 헬스케어, 커머스, 모빌리티, B2B SaaS)마다 그 업무에서 **실제로 자주 부딪히는 대립 쌍**을 고른다(현업 painpoint 조사 `docs/painpoints.*` 형식 재사용, 출처 필수).
2. 조합마다 시나리오 후보 2~3개를 만든다. 각 후보는 다음을 갖는다.
   - `hidden.pair`: 측정하는 대립 쌍(지원자에게 비공개)
   - `hidden.control`: 섞여도 되는 독립 차원
   - `options`: 2~3개 선택지. 각 선택지는 쌍의 한쪽 극 또는 통합안에 대응. **"정답처럼 보이는" 선택지가 없어야 함**(파일럿에서 한 선택지 쏠림 > 70%면 수정)
   - `prompt`: 지원자에게 보이는 상황 + "어떻게 하시겠어요? 이유도 말해 주세요"
3. 기존 3자 대화 흐름에 넣는다: 소통(상황 파악) → 조율(두 페르소나가 각각 A, B 극을 대변) → **타협(선택지 제시, 선택+의견)** → 설득(선택을 상대 페르소나에게 납득시키기).
4. 관찰: 선택 자체(어느 극) + 근거의 질(근거 인용, 상대 입장 인정, 통합안 제시)을 따로 기록한다. 선택은 **성향 정보**이고 좋고 나쁨이 아니며, 근거의 질만 C01~C05 행동 근거로 쓴다.

## 6. 검증 계획
- 파일럿(팀원·지인 n ≥ 20): 선택지 쏠림, 같은 사람의 재응답 일치도(2주 간격, κ), 평가자 2인의 근거 코딩 일치도(κ ≥ .60).
- 설문 점수와의 수렴 타당도(선택: 파일럿 참가자가 단축 PVQ/HEXACO를 함께 응답 → 시나리오 선택과의 상관).

## 7. 리스크
- 공개 데이터는 비확률·해외 중심 표본 → **구조(관계 유형)** 판단에만 쓰고 한국 지원자 규준으로 쓰지 않는다. 한국 표본(D4)으로 구조 유지 여부를 확인한다.
- 성향 선택을 "합격 기준"으로 쓰면 AI 기본법상 고영향 판정 위험과 공정성 문제가 생긴다 → 리포트는 "선택 경향 + 근거"만 보여 주고 점수화하지 않는다.
- 라이선스: openpsychometrics 데이터의 이용 조건(비상업 CC 계열로 알려짐, 다운로드 시 동봉 문서로 확인 필요) → 연구·설계 근거로만 쓰고 원자료는 저장소에 커밋하지 않는다(`data/raw/` gitignore).
