## 추가로 보여 줄 수 있는 흐름

- **HITL 체크리스트**: 로그인 → `/admin/inbox`(계정 승인, 리포트 공개 승인, REVIEW_ERROR, REPORT_FAILED) → 결정 → `/admin/working`(재개 진행) → `/admin`.
- **같이 보는 과제·마크업**: 지원자가 코드 과제의 줄을 골라 우려를 남기면 담당 페르소나가 그 줄을 열어 답하고, 관리자 상세의 "심어 둔 확인 지점"에서 발견/놓침으로 보인다(체크포인트는 지원자에게 나가지 않음).
- **첫 메시지 실패 복구**: START가 실패하면 지원자 화면에 "다시 시작하기"(`POST /api/sessions/{id}/restart`).
